Como publicar no GitHub Pages

Passo a passo rápido para deixar este site online gratuitamente.

  1. Crie uma conta no GitHub: Caso ainda não tenha, cadastre-se no site oficial github.com.
  2. Crie um novo repositório: Clique no botão "+" no canto superior do GitHub e selecione "New repository". Dê o nome de seu-usuario.github.io (substituindo pelo seu nome de usuário).
  3. Envie este arquivo HTML: Faça o upload do seu arquivo com o nome exato de index.html para o repositório principal (Branch main).
  4. Ative o GitHub Pages: Vá até a aba Settings do seu repositório > Pages. Na opção Source, selecione a branch main e clique em Save.
  5. Acesse seu site! Em alguns minutos, seu site estará visível para todo mundo no link https://seu-usuario.github.io.
